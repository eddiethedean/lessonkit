# Slide Deck example

Golden path for **Framework 1.3.0** `SlideDeck` (H5P Course Presentation): multi-slide navigation, keyboard controls, scored assessments, and session resume.

```bash
# From repo root (after npm run build:packages)
npm -w lessonkit-example-slide-deck run dev
```

See [`lessonkit.json`](lessonkit.json) for `checkId` parity with the `TrueFalse` on the knowledge-check slide.
