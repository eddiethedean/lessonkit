# Branching Scenario example (1.5.0)

Golden path for `BranchingScenario`, `BranchNode`, and `BranchChoice` with visited-path scoring and session resume.

```bash
npm run dev -w lessonkit-example-branching-scenario
```

After `npm run build`, package with:

```bash
npx lessonkit package --target scorm12 --cwd examples/branching-scenario
```
