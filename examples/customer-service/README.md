# Customer de-escalation

Support-themed course with live chat and voice-call coaching simulations.

## What to look at in `App.tsx`

- Channel-specific lesson flows (chat listening, phone empathy, escalation paths).
- `courseId` **`customer-de-escalation`** with themed `_shared/course-ui` layout.
- `Quiz` and `Reflection` assessments tied to de-escalation skills.

## Run

```bash
npm run build:packages   # from repo root
npm -w lessonkit-example-customer-service run dev
```
