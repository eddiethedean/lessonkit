# Interactive book demo

Minimal compound-container example — `InteractiveBook` with nested `Page` blocks (1.2 API).

## What to look at in `App.tsx`

- `InteractiveBook` with `blockId`, `showBookScore`, and child `Page` components.
- `Accordion` and `TrueFalse` inside pages; `courseId` **`interactive-book-demo`**.

## Run

```bash
npm run build:packages   # from repo root
npm -w lessonkit-example-interactive-book run dev
```
