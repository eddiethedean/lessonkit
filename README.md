# LessonKit

LessonKit is a React-first learning experience development framework.

## Repository layout

```text
lessonkit/
├── packages/
│   ├── core/
│   ├── react/
│   ├── xapi/
│   ├── scorm/           (planned)
│   ├── accessibility/
│   ├── themes/
│   └── cli/
├── examples/
├── docs/
└── templates/
```

## Quick start (workspace)

```bash
npm install
npm run build
```

## Packages

- `@lessonkit/core`: shared types + runtime primitives
- `@lessonkit/react`: React components + hooks (MVP)
- `@lessonkit/xapi`: xAPI statement generation (MVP)
- `@lessonkit/accessibility`: accessibility helpers (MVP stub)
- `@lessonkit/themes`: theming primitives (MVP stub)
- `@lessonkit/cli`: `lessonkit` commands (MVP stub)
