# LessonKit E2E / conformance

Playwright tests and packaging conformance scripts for **0.9.x** export parity.

## Prerequisites

- **Node.js 20+**
- `unzip` on `PATH` (SCORM unpack)
- From repo root: `npm ci`

## Commands

```bash
# Full Playwright suite (packages artifacts on first run; reuses e2e/.artifacts/manifest.json)
npm run test:e2e

# Force rebuild of packages + golden artifacts before tests
E2E_FORCE_REBUILD=1 npm run test:e2e

# Interactive UI mode
npm run test:e2e:ui

# LXPack shared conformance matrix (all export targets)
npm run conformance:lxpack

# Golden example standalone + scorm12 package smoke
npm run conformance:golden
```

## Layout

| Path | Purpose |
|------|---------|
| `tests/vite/` | Vite preview — keyboard, telemetry, smoke |
| `tests/standalone/` | Packaged LXPack native shell (quiz nav in shell, not React sign-off route) |
| `tests/scorm12/` | SCORM 1.2 ZIP with injected `window.API` LMS mock + native assessments |
| `tests/parity/` | Cross-surface checklist |
| `support/scorm/` | SCORM 1.2 API mock and ZIP unpack |
| `.artifacts/` | Generated by `global-setup` (gitignored) |

## SCORM mock

Tests inject a SCORM 1.2 `window.API` before navigation. Assertions read `window.__scorm12Test.store` and `log` for `LMSSetValue` calls (lesson status, scores).

## CI

The **E2E** and **Packaging smoke** jobs in [`.github/workflows/checks.yml`](../.github/workflows/checks.yml) run these checks on Node 20.
